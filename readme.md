data.win file is the file with all the data of the game in it (duhh)



Modtool folder
 - Contains exported data.win file (folder .exportedfiles)
 - Contains folders .ChangedFiles (has the same folders as exported data.win)
 - .Drawings contains .kra files of changed textures. to be editted later in krita
 - .dataWinExports contains all previous versions of the mod with versioning
 - .CleanProject has the development project in UndertaleModTool. Including the clean data.win from Another Door
 - .importfiles contains the .ChangedFiles which overwrites the .dataWinExports


How to mod (For me / other modders)
 - Open clean .win from "C:\..dev\AnotherDoorMod\ModTool\CleanProject" with undertaleModTool
 - Scripts > Import > ImportType > select import folder from .importfiles
 - File > Save > Yes
 - The modded version will be in "C:\..dev\AnotherDoorMod\ModTool\CleanProject\MODPROJECT"
 - The clean version will stil be in "C:\..dev\AnotherDoorMod\ModTool\CleanProject"
